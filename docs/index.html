Про сайт

NBU Rate

NBU Rate — незалежний український фінансовий сервіс для зручного перегляду офіційних курсів НБУ, порівняння курсів банків, конвертації валют і відстеження криптовалют та акцій.

Історичні графіки, калькулятори та відкриті JSON-дані допомагають аналізувати зміни курсів. Дані автоматично оновлюються через GitHub Actions; доступність і свіжість залежать від джерела. Сайт можна встановити як PWA.

Проєкт не є банком, брокером чи криптобіржею та не проводить фінансових операцій. Інформація має довідковий характер.

Регіональні котирування та повне покриття банків поки не підтримуються: це потребує окремих інтеграцій, перевірки джерел і додаткових ресурсів. Ми розширюватимемо покриття за наявності можливостей.

Політика конфіденційності

Які дані ми збираємо

Сайт «Курс НБУ» не потребує реєстрації та не запитує ім’я чи email. Хостинг і зовнішні сервіси можуть обробляти технічні дані запитів (наприклад IP-адресу).

Що зберігається

Усі налаштування (тема, мова, вибір валют) зберігаються локально у браузері через localStorage.

Зовнішні запити

Курси валют читаються з публічного репозиторію на GitHub, який оновлюється з офіційних сайтів та API банків (bank.gov.ua, api.privatbank.ua, api.monobank.ua, api.coingecko.com). Логотипи та прапори завантажуються з файлів цього сайту; для відсутніх зображень використовуються текстові позначення.

Добровільна підтримка

Посилання на Donatello відкриває зовнішній сервіс. Оплата та обробка даних донату регулюються його умовами та політикою конфіденційності.
