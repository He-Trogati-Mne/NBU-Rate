Політика конфіденційності

Які дані ми збираємо

Сайт «Курс НБУ» не збирає жодних персональних даних: ні ім'я, ні email, ні історію, ні місцезнаходження.

Що зберігається

Усі налаштування (тема, мова, вибір валют) зберігаються локально у браузері через localStorage.

Зовнішні запити

Курси валют читаються з публічного репозиторію на GitHub, який оновлюється з офіційних сайтів та API банків (bank.gov.ua, api.privatbank.ua, api.monobank.ua, api.coingecko.com). Іконки криптовалют — cdn.jsdelivr.net, cryptologos.cc. Прапори — flagcdn.com.
