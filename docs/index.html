Які дані ми збираємо

Розширення «Курс НБУ» не збирає жодних персональних даних: ні ім'я, ні email, ні історію, ні місцезнаходження.

Що зберігається

Усі налаштування (тема, мова, вибір валют, власні кольори) зберігаються локально в браузері через API chrome.storage.

Зовнішні запити

Єдиний зовнішній запит — до офіційного API Національного банку України (bank.gov.ua).

Дозволи

  • storage — збереження налаштувань
  • alarms — періодичне оновлення курсів
  • https://bank.gov.ua/* — запит курсів
