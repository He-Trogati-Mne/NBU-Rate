## Підтримувані версії

Оновлення безпеки випускаються лише для **останньої опублікованої версії**.

| Версія | Статус |
|:---|:---:|
| Остання в магазині (Edge · Firefox) | Підтримується |
| Збірки з гілки `main` | Підтримується |
| Попередні версії | Не підтримуються |

> Якщо ви на старій версії — просто оновіться до актуальної.

## Як повідомити про вразливість

> **Будь ласка, не створюйте публічний Issue для проблем безпеки.**
> Публічне розкриття до виправлення може нашкодити користувачам.

Обери зручний приватний канал:

### 1. GitHub Private Vulnerability Reporting — рекомендовано

1. Відкрий вкладку [**Security**](https://github.com/He-Trogati-Mne/NBU-Rate/security) репозиторію
2. Натисни **«Report a vulnerability»**
3. Заповни форму — створиться приватний advisory, видимий лише мейнтейнеру

### 2. Email

Якщо GitHub недоступний — напиши на адресу з профілю [@He-Trogati-Mne](https://github.com/He-Trogati-Mne) з темою:

```
[SECURITY] NBU-Rate — короткий опис проблеми
```

## Що варто вказати у звіті

Чим детальніше — тим швидше виправлення.

| Пункт | Опис |
|:---|:---|
| **Тип вразливості** | XSS, injection, витік даних, обхід дозволів, supply chain… |
| **Версія + браузер** | Наприклад: v1.2.3 · Edge 130 |
| **Кроки відтворення** | Покроково, з мінімальним прикладом |
| **Очікувано / фактично** | Що мало статись і що сталось |
| **Вплив** | Що саме може зробити атакуючий |
| **Proof of Concept** | Код, скріншот, відео або PoC-репозиторій |
| **Пропозиція фіксу** | Якщо є — буде дуже до речі |
| **Атрибуція** | Як вас згадати у подяках |

## Що НЕ є вразливістю

Щоб не витрачати час одне одного — ось що **не** вважається проблемою безпеки в цьому проєкті:

| Не є вразливістю | Чому |
|:---|:---|
| Відсутність CSP на `bank.gov.ua` | Це не наш домен — ми лише читаємо публічний JSON |
| Запит до API НБУ | Це єдина задокументована функція розширення |
| Зберігання в `chrome.storage.sync` | Синхронізація під акаунтом користувача — задокументована поведінка |
| Неточні курси | Дані надходять напряму з офіційного API НБУ |
| Відсутність аналітики / трекінгу | Це свідома характеристика, а не недолік |
| «Не працює на старому Edge» | Обмеження сумісності, а не безпека |

> Сумніваєтесь? Краще повідомте — ми розберемось.

## Модель загроз

Розширення має **мінімальну поверхню атаки** завдяки архітектурним рішенням.

### Що ми робимо

- **Manifest V3** — сучасний стандарт із суворішими обмеженнями, ніж MV2
- **Service Worker** замість постійного background page — менше часу виконання
- **Vanilla JS** — жодних сторонніх бібліотек, бандлерів чи npm-залежностей
- **Inline SVG** для прапорів — без зовнішніх CDN та запитів
- **Мінімум дозволів** — `storage`, `alarms` та доступ до `bank.gov.ua`
- **Єдиний зовнішній запит** — офіційний API НБУ:

  ```
  https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange?json
  ```

### Чого ми НЕ робимо

- Не виконуємо код ззовні (`eval`, `new Function`, remote scripts)
- Не завантажуємо віддалені ресурси (шрифти, скрипти, CSS)
- Не використовуємо аналітику, трекери, рекламу
- Не надсилаємо жодних даних користувача на сторонні сервери
- Не маємо npm-залежностей, які можна скомпрометувати

### Дозволи та їх межі

| Дозвіл | Що дозволяє | Що НЕ дозволяє |
|:---|:---|:---|
| `storage` | Читати/писати власні налаштування | Читати дані інших розширень чи вкладок |
| `alarms` | Планувати оновлення раз на годину | Виконувати код у фоні без обмежень |
| `https://bank.gov.ua/*` | Читати публічний JSON курсів | Читати інші сайти, кукі, історію |

**Розширення не має доступу до:**

- вкладок (`tabs`), історії (`history`), закладок (`bookmarks`)
- буфера обміну (`clipboardRead` / `clipboardWrite` без дії користувача)
- файлової системи (`downloads`, `fileSystem`)
- камери, мікрофона, геолокації
- вмісту сторінок (`content_scripts` відсутні)

## Ланцюг постачання (Supply Chain)

Проєкт **навмисно** не має зовнішніх залежностей:

- Немає `package.json`, `node_modules`, bundler'ів
- Немає CDN-ресурсів
- Немає віддаленого коду (RCE неможливий)
- Увесь код — у репозиторії, відкритий для аудиту

> Це означає, що скомпрометувати розширення через сторонню бібліотеку **неможливо** — такої бібліотеки просто немає.
