Політика конфіденційності — Курс НБУ

Останнє оновлення: 14 вересня 2026

Які дані ми збираємо

Розширення «Курс НБУ» не збирає жодних персональних даних користувача: ні ім'я, ні email, ні історію, ні місцезнаходження.

Що зберігається

Усі налаштування (тема, мова, вибір валют, власні кольори) зберігаються локально в браузері користувача через API chrome.storage і, за бажанням користувача, синхронізуються між його пристроями через акаунт Microsoft.

Зовнішні запити

Єдиний зовнішній запит — до офіційного API Національного банку України (bank.gov.ua) для отримання курсів валют. Жодна інформація про користувача при цьому не передається.

Дозволи

  • storage — для збереження налаштувань.
  • alarms — для періодичного оновлення курсів.
  • https://bank.gov.ua/* — для запиту курсів.
