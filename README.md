## Що нового у v2.7.0

- **Вибір джерела курсу** — НБУ, ПриватБанк та МоноБанк. НБУ показує офіційний курс, ПриватБанк і МоноБанк — купівлю та продаж.
- **Оновлений візуал** — сучасніший дизайн, плавні анімації, градієнти, покращені картки валют та кнопки.
- **Виправлено білу вспишку при F5** — при перезавантаженні сторінки з темною темою більше не з'являється білий фон (анти-FOUC).
- **Більше валют** — додано AED, SAR, TND, EGP, DZD, AZN, GEL, KZT, MYR, THB, MDL, ZAR, RSD, XDR та метали XAU/XAG/XPT/XPD.
- **Класичний дизайн** — у налаштуваннях можна повернути вигляд v2.6 і раніше.

## Можливості

**Джерела курсу.** Три джерела на вибір — **НБУ** (офіційний курс), **ПриватБанк** та **МоноБанк** (з купівлею та продажем). Перемикання миттєве прямо у вікні розширення.

**Валюти.** Понад 40 валют з офіційного API НБУ — USD, EUR, GBP, PLN, CNY, CHF, JPY, CAD, AUD, TRY, SEK, NOK, DKK, CZK, HUF, RON, ILS, KRW, SGD, HKD, NZD, MXN, INR, TND, EGP, DZD, AED, SAR, AZN, GEL, KZT, MYR, THB, MDL, ZAR, RSD, XDR та метали XAU, XAG, XPT, XPD. Прапори країн, вибір валют — показуй лише те, що потрібно.

**Оформлення.** 4 теми — Світла, Темна, Системна, Власна. Власна тема з HEX-піпеткою. 6 готових пресетів: Midnight, Nord, Dracula, Sepia, Forest, Rose. Дві мови — Українська та English. Класичний дизайн v2.6 на вибір.

**Швидкість.** Миттєве відкриття завдяки кешуванню. Оновлення раз на дві години у фоні. Значок на іконці з поточним курсом USD. Стійкість до збоїв та rate-limit (429).

**Приватність.** Жодної аналітики, трекінгу чи реклами. Зовнішні запити лише до офіційних API обраного джерела.

**Доступність.** Режим для дальтоніків з 4 палітрами (Okabe-Ito, для червоно-зеленого, синьо-жовтого, чорно-біла). Символи замість кольору. Підкреслення змін курсу. Великий шрифт (100–150%).

## Використання

**Перегляд курсів.** Клікніть на іконку розширення на панелі браузера — відкриється вікно з курсами обраних валют.

**Вибір джерела.** У вікні розширення вгорі є перемикач **НБУ / ПриватБанк / МоноБанк**. Вибір зберігається й використовується також для значка на іконці.

**Налаштування.** Шестерня у правому верхньому куті вікна розширення. Там можна змінити тему, кольори, мову, джерело курсу, набір валют, параметри доступності та увімкнути класичний дизайн.

**Значок на іконці.** Показує поточний курс USD з обраного джерела. Колір значка підлаштовується під акцентну тему.

## Технології

**Manifest V3** — сучасний стандарт браузерних розширень

**Service Worker** — замість застарілого background page

**Vanilla JS** — без фреймворків, бандлерів та збірників

**CSS-змінні** — для динамічної теми та анти-FOUC

**chrome.storage.sync** — синхронізація налаштувань між пристроями

**OffscreenCanvas** — генерація іконок на льоту під акцентну тему

**PNG-прапори** — локальні зображення без зовнішніх запитів

**Chart.js** — графіки історії курсів на сайті

**Okabe-Ito** — науково обґрунтована палітра для дальтоніків

## Дозволи

| Дозвіл | Навіщо |
|---|---|
| `storage` | Зберігає тему, мову, вибір валют та джерела |
| `alarms` | Оновлює курси раз на дві години |
| `https://bank.gov.ua/*` | Отримання курсів з API НБУ |
| `https://api.privatbank.ua/*` | Отримання курсів з API ПриватБанку |
| `https://api.monobank.ua/*` | Отримання курсів з API МоноБанку |

Розширення не збирає жодних персональних даних. Запити йдуть лише до обраного джерела курсу.

## Приватність

Розширення не збирає жодних персональних даних:

- Жодної аналітики
- Жодного трекінгу
- Жодної реклами
- Жодних сторонніх запитів

Усі налаштування зберігаються локально в браузері через `chrome.storage.sync` та синхронізуються між пристроями під акаунтом користувача.

**Зовнішні запити** — лише до офіційних API обраного джерела:
```text
https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange?json
https://api.privatbank.ua/p24api/pubinfo?exchange&json&coursid=11
https://api.monobank.ua/bank/currency
```


Детальніше — на [сторінці політики конфіденційності](https://he-trogati-mne.github.io/NBU-Rate/#privacy).
